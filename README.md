# Weaver - AI Website Builder

<img width="2559" height="1439" alt="image" src="https://github.com/user-attachments/assets/34f7559b-e68f-4662-a650-42a0e3ddf328" />

Full SaaS integrated with custom AI agent and Prisma database to allow creating, viewing, editing and testing impressive websites in a matter of seconds.

## Install Packages
```bash
npm i
```

## Setup .env file

```bash
DATABASE_URL=
NEXT_PUBLIC_APP_URL=

# Open AI
OPENAI_API_KEY=

# E2B
E2B_API_KEY=

# Clerk
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=
CLERK_SECRET_KEY=
NEXT_PUBLIC_CLERK_SIGN_IN_URL=
NEXT_PUBLIC_CLERK_SIGN_IN_FALLBACK_REDIRECT_URL=
NEXT_PUBLIC_CLERK_SIGN_UP_FALLBACK_REDIRECT_URL=
NEXT_PUBLIC_CLERK_SIGN_UP_URL=
```

## Start the app

```bash
npm run dev
```
